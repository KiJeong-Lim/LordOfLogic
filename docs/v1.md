## Scopes and custom entries

Run `cabal run -v0 lol -- example/V1Scopes.lol` to see one expression
compute to `red` in the left scope and `blue` in the right scope. The
same file searches for both generalised functions and contains a proof
you can step through.

A scope groups interpretations. A custom entry defines a separate grammar.
This example declares an infix operator and makes a delimiter available.
`Close Scope` restores the previous default interpretation. The suffix
`%calc` selects the scope for one expression.

```coq
Declare Scope calc_scope.
Delimit Scope calc_scope with calc.
Infix "⊕" := mix (at level 50, left associativity) : calc_scope.
Open Scope calc_scope.
Definition doubled : Item := seed ⊕ seed.
Close Scope calc_scope.
Definition explicit_scope : Item := (seed ⊕ seed)%calc.
```

To embed another grammar in terms, declare its entry, add productions to it,
and use one term notation to enter it. Its operators and terminals need no
interpretation in ordinary terms.

```coq
Declare Custom Entry expression.
Notation "<{ x }>" := x (x custom expression).
Notation "'atom'" := seed (in custom expression at level 0).
Notation "x + y" := (mix x y) (in custom expression at level 50, left associativity).
Check <{atom + atom}>.
```

Use `x constr` in a production to read that argument in the ordinary term
grammar. `x custom entry at level 50` selects an entry and limits the
precedence it consumes. A notation may specify `only parsing`, `only printing`
or a `format` string. Extra spaces inside the quoted production also control
the spacing of that notation. In a format each extra space prints as a space, `'/'`
marks a possible line break, and `'//'` forces one. Use `'[v  '` and `']'` to
indent the contents of a vertical box by two spaces. `--explicit` prints the
checked declarations with global references for rereading.

Use `Bind Scope calc_scope with Item.` to select a grammar when the
expected type of an argument is `Item`. For an individual function,
`Arguments mix x%_calc_scope y%_calc_scope.` selects the scope for its two arguments,
provided its declared binders are named `x` and `y`. An explicit
`%calc` at the use site also works after `Close Scope`.

Use `Disable Notation "_ ⊕ _" (only printing) : calc_scope.` to keep
reading the operator while showing the underlying application.
`Enable Notation "_ ⊕ _" (only printing) : calc_scope.` restores its
printed form. When two imported modules declare a custom entry called
`expression`, write `x custom M.expression` to extend a particular
module's grammar. A wrapper written in that module keeps its original
entry after importing the other module.

Notation can take a constructor pattern in the part of Gallina accepted by
LoL. Its `match` branches support flat constructor patterns. A constructor
nested inside another pattern and an `as` alias in a pattern need further
language support. Rocq's inspection commands `Print Scope`, `Print Scopes`,
`Print Notation` and `Locate` are unavailable in this release.

## Finding statements

`Search _ "twice".` lists visible statements with “twice” in their name.
`Search (f _).` looks for an occurrence matching that application. Combine
term patterns and quoted strings, prefix an item with `-` to exclude it, and
use `in M` or `outside M` to restrict a query to a module. Search in a proof
also sees the local hypotheses. It leaves the current goal and Undo history
intact.

## Sections

```coq
Section Operations.
Context (A : Set) (combine : forall _ : A, forall _ : A, A).
Definition twice (a : A) : A := combine a a.
End Operations.
Check twice.
```

Inside the section, `A` and `combine` are available to each declaration.
At `End Operations.` the declarations gain parameters for the section
variables on which they depend. The section variables disappear from the
surrounding scope.

## Editor

Install the bundled VS Code extension, open this repository as a trusted
workspace, and set `lordOfLogic.executable` to the absolute path printed by
`cabal list-bin exe:lol`. Open `example/V1.lol`, put the cursor on
`intros P h.`, then choose **LoL: Check to Cursor** from the Command
Palette. **LoL: Next Command** executes the next sentence. **LoL: Previous Command** steps back.
Editing an earlier sentence invalidates the goals that depended on it.
Installation and key bindings are in the
[extension guide](../editors/vscode/README.md).

## Reproducing the checks

On Linux, build `exe:lol`, put Rocq 9.2.0, Python 3 and Node on PATH, then
run `bash test/v1.sh`. To select another installation of the same Rocq
release, run `ROCQ=/absolute/path/to/rocq bash test/v1.sh`. The driver runs
the grammar and kernel comparisons and the editor protocol tests under time
and memory limits. Using the editor itself requires VS Code and the LoL
executable.
